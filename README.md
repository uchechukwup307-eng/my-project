Student Portfolio and Academic Management Website

Project Description

This project is a student portfolio and academic management website developed as part of the requirements for the MIVA-CSC 106 – Introduction to Web Technologies course at Miva Open University.

The website introduces me as a Software Engineering student and provides information about my background, skills, interests and projects. It also includes an academic planner that helps users organise their academic tasks.

Features

The website contains five main pages:

- Home: Introduces the website and provides a welcome message.
- About Me: Displays my educational background, interests and goals.
- Projects: Presents projects and activities I have worked on.
- Academic Planner: Allows users to add, complete and delete academic tasks.
- Contact: Provides a form through which visitors can prepare messages to contact me.

The academic planner uses browser local storage to save tasks, allowing them to remain available after refreshing the page.

Technologies Used

- HTML – For the structure and content of the website.
- CSS – For styling, layout and responsive design.
- JavaScript – For interactive features and task management.
- Visual Studio Code – For writing and editing the code.
- GitHub Pages – For hosting the website.
